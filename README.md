# 🧾 Self Expense Detector

A simple Python project that automatically detects and categorizes your expenses from a CSV file.

## 📂 How to Use
1. Create a CSV file named `expenses.csv` with the columns:
Example:
Uber ride,12.50
Pizza Hut,20.00
Netflix subscription,15.99
Electricity bill,60.00
Grocery store,45.30

 Run the Python script:
```bash
python expense_detector.py
